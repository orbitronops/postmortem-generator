## Root cause

OOMKilled — the checkout-api container exceeded its memory limit (511Mi used of 512Mi). The container was terminated with exit code 137 and restarted, which repeated until the limit was raised.

## Contributing factors

- The checkout-api memory limit was set at deployment time and had not been reviewed against current usage.
- Memory usage grows with request volume, so the limit was reached during the morning traffic peak.
